# 学伴 AI 助教

HTML5 课程作业：使用原生 HTML、CSS、JavaScript 制作的注册和登录页面。以蓝白配色、学习笔记装饰和“智能答疑、陪伴学习”的平台理念呈现学习平台特色。目前实现的是表单前端演示，未实现 AI 答疑功能。

## 文件结构

```text
ai-teaching-assistant/
├── register.html  注册页面、平台介绍、用户协议
├── login.html     登录页面、平台介绍
├── style.css      公共样式、学习装饰、响应式布局、焦点样式
├── script.js      密码一致性、显隐切换、演示提交
├── README.md      项目介绍与使用方法
└── FEATURES.md    功能分类、实现位置与验证清单
```

上述为本项目相关文件，目录中可能还包含既有的截图目录等内容。

## 打开方法

1. 保持四个 HTML/CSS/JavaScript 文件在同一文件夹。
2. 双击 `register.html` 或 `login.html`，用现代浏览器打开。
3. 点击卡片底部的“前往登录”或“前往注册”切换页面。
4. 更新文件后刷新页面；需要开启 JavaScript 以体验完整交互。

无需安装依赖、构建或启动服务器。所有资源均以相对路径引用；字体采用本机系统字体，装饰由 HTML 和 CSS 构成，不依赖网络图片或字体。

## 已实现功能

- 注册：用户名、邮箱、密码、确认密码、学生/教师身份、学科、必选用户协议。
- 登录：邮箱和密码表单。
- 用户名限定为 3～16 位英文字母、数字或下划线；邮箱使用原生邮箱校验；密码至少 8 位。
- 修改任意密码框都会重新检查一致性；密码可独立显示或隐藏。
- 合法提交显示“前端演示成功，未连接服务器”，并清空所有密码、恢复隐藏状态。
- 桌面双栏、900px 及以下单栏、480px 及以下进一步调整间距与密码排列。
- 语义化结构、关联标签、可见格式说明、键盘焦点、动态状态播报属性。

## 演示局限

没有后端、数据库、账号创建、身份认证、邮件验证、会话或真实 AI 服务。注册填写的信息不会成为可登录账号，登录仅检查格式。身份和学科仅是表单选择，不会改变权限或推荐内容。

页面脚本不发送表单请求，也不使用本地存储保存密码；密码仅在输入期间存在于页面控件中，成功提交后清空。`autocomplete` 是给浏览器的填写提示，浏览器或密码管理器自身的保存行为由用户设置控制。请使用虚构信息和演示密码。

原生校验依赖浏览器，提示语言和自动填充体验可能随浏览器设置变化。若禁用 JavaScript，密码一致性、显隐、阻止默认提交及成功提示不会工作；该模式不属于完整演示的支持范围。前端校验不能替代真实系统的服务端校验。

## 验证状态

本轮实际执行：`node --check script.js`；使用 Node 内置模块进行 HTML 属性与相对路径静态检查、无外部资源检查，以及模拟表单对象的脚本逻辑检查，均通过。Node 仅用于开发检查，打开页面不需要安装 Node。

模拟检查覆盖密码不一致、修改任意密码框后的恢复、显隐状态、阻止默认提交、清空正在显示的密码及清除旧成功提示。它不是浏览器端到端测试，也不验证浏览器原生约束行为。

尚未进行实际浏览器渲染、手机设备、键盘全流程、自动填充或读屏测试。详细待人工验收步骤见 `FEATURES.md`；不将这些项目记为已通过。
